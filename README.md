# AI4Paper

AI4Paper is building an open-source, AI-assisted workspace for the complete academic paper-writing workflow.

The organization overview, repository descriptions, and architecture figure are maintained in [`profile/README.md`](profile/README.md). It covers the Python-based [`apaper-mcp`](https://github.com/ai4paper/apaper-mcp), the native DSH [`apaper-plugin`](https://github.com/ai4paper/apaper-plugin), and the DSH Web-based [`ipaper`](https://github.com/ai4paper/ipaper) user interface.
